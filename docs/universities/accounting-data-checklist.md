- 資料の位置付け
  - 大学別に管理する会計データを共有するための説明用一覧
  - 今回の範囲：金額明細・小計・合計を記入した電子データの生成
  - 項目の根拠・未確定事項は[大学別調査](README.md)を参照
  - 提供サンプルに基づく整理。最新の正式書式・必須条件は別途確認する

- 今回の対象
  - 大学の書式に、金額明細・小計・合計を記入したExcel／PDFを生成する
  - ExcelにはSUM関数などの集計式を含める
  - 明細が複数ページ・複数シートにまたがっても、漏れや重複なく出力する
  - 印刷・自署・捺印・大学への提出作業は対象外
  - 初期対応の対象大学：法政・横浜国立・明治
  - 学習院・早稲田・立命館：追加の書式調査として掲載。初期対応への追加を意味しない

- 共通で管理する項目
  - 団体名
  - 対象年度・対象期間
  - 取引ごとの情報
    - 収入／支出の区分
    - 取引日・購入日
    - 金額
    - 会計項目・費目
    - 内訳・摘要
    - 大学の書式に応じた用途・備考
  - 繰越を記入する場合の開始残高
    - 不明な残高を0円として扱わない
  - 自動計算する項目
    - 費目別・内訳別の小計
    - 収入合計・支出合計
    - 期末残高：開始残高＋収入－支出

- [法政大の場合](hosei.md)
  - 出力する内容
    - 対象期間の支出明細を、費目ごとにすべて記入する
    - 費目別の小計・支出の総合計を記入する
    - 提供サンプルは支出明細用。収入書式は別途確認が必要
  - 支出ごとに管理する項目
    - 費目
      - 消耗品費／印刷製本費／通信・郵便費
      - 機材用具費（購入・修理）
      - 演劇等舞台衣裳費（購入・レンタル・修理）
      - 会場装飾費（宴会除く）
      - 書籍等資料購入費／運搬費／学外施設利用料
      - 講師等への謝礼代／大会参加費（エントリー代のみ）
      - 外部団体登録料／廃液等廃棄物処理費／保険費
      - 学祭費／交通費／宿泊・飲食代／贈答品
      - 宴会・納会・レセプション代
      - 追加費目にも対応
        - サンプル内の追加例：教材費／サーバー維持費
    - 金額
    - 購入年月日
    - 内訳：何を購入したか
    - 用途：どの活動・目的で使用したか
  - 領収書の管理
    - 書式では、明細のNO.と領収書上の番号を一致させる必要がある
    - 各支出明細が、どの領収書に対応するかを管理する
    - 機能として検討する内容
      - 登録済みの領収書を支出明細へ紐付ける
      - 領収書画像をアップロードし、対応する支出明細から確認できるようにする
      - 立替申請で登録した領収書を、承認後の支出からも参照できるようにする
      - 画像がない場合も、領収書の識別子・番号で対応を管理できるか検討する
    - 既存の立替申請・支出登録には画像アップロード機能があるため、再利用・拡張を検討する
    - 画像のアップロードと、提出区分・帳票番号の管理は別の情報として扱う
    - 領収書画像のアップロードを全件必須にするかは未確定
    - 1枚の領収書を複数の支出・費目へ分ける場合の対応方法は要確認
    - 今回は、金額明細と領収書の対応を確認できることを検討対象とする
    - 領収書画像のExcel／PDFへの貼付、紙の原本整理・提出作業は今回の必須機能に含めない
  - NO.欄まで記入する場合に管理する項目
    - 明細と領収書の対応
    - 領収書の提出区分
      - 決算で提出：`1`など
      - 活動規模の補助金申請で提出済み：`規模1`など
      - 正課外の経費補助で提出済み：`正課外1`など
      - 活動実態の補助金申請で提出済み：`実態1`など
    - 既に付与されている領収書番号
    - 連番の範囲・再利用方法は要確認
    - ページ・シートが変わっても、同じ領収書との対応を維持する
    - ファイルを生成しただけで、大学への提出済み状態には変更しない
  - 必須入力にするか未確定の項目
    - 対象金額／対象外金額／備考
    - 原本では非表示列。入力者・用途・必須性を確認してから扱いを決める

- [学習院大の場合](gakushuin.md)
  - 出力する内容
    - 収入・支出を費目別、必要に応じて内訳別に集計する
    - 前年度繰越金・次年度繰越金を記入する
  - 収入の分類
    - 輔仁会予算
    - 助成金
      - 特別助成金／指定助成金／部会助成金
      - 学外施設使用団体助成金
      - 全国大会出場に伴う援助金
      - 父母会の一般助成金・学生活動助成金
      - 輔仁会激励金・課外活動褒賞金
      - 上記は見本の内訳。実際に受けた制度に対応させる
    - 部費
    - 合宿遠征費等個人負担金
    - OB・OG会からの補助
    - 預金利子
  - 支出の分類
    - 備品費／消耗品費／運搬費／交通費／通信費
    - 連盟登録費／試合参加費／合宿遠征費
    - 印刷費／雑費
  - 内訳を記入する場合に管理する項目
    - 助成金の種類
    - 部費の徴収月
    - 大会名・合宿名
    - 物品などの内訳名
    - 備考
      - 単価・人数を記載する場合：その単価・人数
      - 資金源を記載する場合：どの助成金等から支出したか
      - 単価・人数・資金源は、全取引の必須項目とはしない
  - 残高・集計
    - 前年度繰越金：預金と保有現金の合計
    - 次年度繰越金：開始残高＋当年度収入－当年度支出
    - 帳票の収入合計には前年度繰越金を含める
    - 帳票の支出合計には次年度繰越金を含める
    - 内訳と費目小計を二重に加算しない

- [早稲田大の場合](waseda.md)
  - 金額明細の生成対象
    - 会計報告シートの年度収支・繰越を記入する
    - 活動実績シート・補助金申請給付状況シートの完成は今回の対象外
  - 収入の分類
    - サークル会費
    - OB・OG等寄付金
    - 企業等協賛金
    - 課外活動補助金（大学給付）
    - その他の収入
      - 金額に加えて内訳名を管理する
  - 支出の分類
    - 印刷製本費／消耗品費／用品費／図書資料費
    - 広告宣伝費／通信費／施設利用費
    - 宿泊費／交通費／保険料／賃借料
    - 講師料／委託費／医療費／参加費・登録費／雑費
    - その他の支出
      - 金額に加えて内訳名を管理する
  - 残高・集計
    - 前年度繰越金
    - 次年度繰越金
    - 帳票の収入合計には前年度繰越金を含める
    - 帳票の支出合計には次年度繰越金を含める
    - 過去に領収書を提出済みの支出も、年度の支出へ含める
  - 行数が不足する場合
    - 「その他」の収入・支出欄は、それぞれ10行
    - 超過時の継続方法は要確認。超過分を切り捨てない

- [立命館大の場合](ritsumeikan.md)
  - 出力する内容
    - 対象期間の収入・支出を項目別に集計する
    - 前期繰越金・次期繰越金を記入する
  - 管理する項目
    - 対象期間の開始日・終了日
    - 収入項目名・金額
    - 支出項目名・金額
    - 前期繰越金
    - 次期繰越金の内訳
      - 手元現金
      - 預金
      - 内訳を確認した基準日
  - 項目名の扱い
    - 提供書式の通常の収支欄は自由記入
    - 大学指定の固定選択肢があるとは確認できていない
  - 残高・集計
    - 帳簿上の期末残高と、確認した現金・預金の合計を照合する
    - 残高合計だけから現金・預金の内訳を推定しない
    - 不一致の差額を自動的に預金等へ振り分けない
    - 帳票の支出合計には次期繰越金を含める

- 横浜国立大・明治大の場合
  - 初期対応の対象
  - 正式書式・サンプルが未入手
  - 資料取得後に確認する項目
    - 取引ごとの明細が必要か、費目別集計でよいか
    - 収入・支出の費目一覧
    - 用途・備考・領収書番号などの追加欄
    - 繰越金・残高内訳の扱い
    - 行数超過時の継続方法
