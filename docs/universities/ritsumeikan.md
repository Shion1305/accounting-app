# 立命館: 残高合計だけでは埋まらない

更新日: 2026-09-27

位置付け: 提供サンプルの調査結果。最新の正式規則・運用の確定とは区別する。

[ドキュメント一覧](../README.md)

調査原本: `docs/ritsumeikan/kaikeihoukoku.xlsx`（非同梱）。個人・環境等の識別メタデータを除去した[参照コピー](../references/ritsumeikan.reference.xlsx)を同梱している。セル・数式・コメントの内容を根拠とする書式の調査資料であり、最新版の正式テンプレートとして保証しない。除去対象と確認結果は[資料管理記録](../references/README.md)を参照する。

| 根拠                               | 確認できた情報                                                             | 保存・入力への影響                                                                       |
| ---------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| `Sheet1!A3:N6`、`E4:E6` のコメント | 団体名、教職員の部長・顧問（配置時のみ）、学生代表・会計。自署時は捺印不要 | 年度の役職・担当者情報と紙での確認手順が必要。氏名の印字だけで自署・捺印済みにしない     |
| `Sheet1!J1`、`B8`、`H8` のコメント | 記載日・期間の日付形式                                                     | 作成日と対象期間を取引の日付とは分ける                                                   |
| `Sheet1!H25:M26`                   | 次期繰越金を手元現金と預金に分ける                                         | 総残高だけでは内訳を確定できない。基準日付きの確認残高か、口座別の入出金・振替情報が必要 |
| `Sheet1!A28:A31`                   | 収入合計＝繰越込み支出合計。領収書添付は不要で団体保管                     | 大学ごとに領収書の出力要否が異なる。支出の実額と繰越込み帳票合計を区別する               |

例えば期末残高が10,000円でも、現金2,000円・預金8,000円なのか、現金0円・預金10,000円なのかは収支総額から分からない。現行アプリは立替を承認時に支出へ反映するため、未精算分がある状況では帳簿の残高をそのまま実際の現金・預金と断定もできない。初期範囲で口座管理を全面実装せず、立命館対応時に基準日・確認者付き残高の補完と差異の確認方法を設計する。

## 作成する書類と範囲

`Sheet1`の課外活動団体決算報告書を生成する。団体・担当者・対象期間、費目別の収入と支出、現金・預金別の次期繰越金を含む。領収書は団体保管で、添付用紙はこのサンプルの提出対象に含まれない。

記名欄は生成できるが、自署・捺印の完了は別の作業である。任意の印影画像を自動追加する機能は、この資料から要求しない。

## 帳票生成へ要求する入力形式（提案）

[共通入力](README.md#大学別入力契約の読み方)と、次の型付き `reportContext` を想定する。

| 入力                                                   | 型・単位                       | 必須条件・入力時点                 | 根拠／用途                                               |
| ------------------------------------------------------ | ------------------------------ | ---------------------------------- | -------------------------------------------------------- |
| `organization.name`                                    | 空でない文字列                 | 出力時必須                         | `A3:N3`                                                  |
| `profile.reportDate`                                   | `YYYY-MM-DD`                   | 出力時必須とする案                 | `J1`のコメント                                           |
| `period`                                               | 開始日と排他的終了日のある期間 | この帳票では期間を確定する         | `B8`、`H8`。帳票の終了日表示は排他的終了日の前日         |
| `profile.hasAdvisor`                                   | booleanまたはNULL              | 出力前に配置有無を確認             | `A4`の「配置されている場合のみ」。NULLを未配置扱いしない |
| `profile.advisorName`                                  | 文字列またはNULL               | 顧問等の配置がある場合に必要       | `A4:N4`                                                  |
| `profile.studentRepresentativeName` / `accountantName` | 空でない文字列                 | 出力時必須とする案。対象年度で保存 | `A5:N6`                                                  |
| `openingBalanceYen`                                    | 確認済みの整数円               | 繰越を含む報告で必須               | `A11:G11`                                                |
| `entries[]`                                            | 共通の収入・支出データ         | 期間内の費目別集計に必要           | `A10:M26`                                                |
| `closingBalances.asOf`                                 | `YYYY-MM-DD`                   | 期末の確認日として必須             | 確認残高と対象期間を対応させる                           |
| `closingBalances.cashYen` / `depositYen`               | 非負の整数円、未確認はNULL     | 両方を確認してから提出用出力       | `H25:M26`。預金はこの書式では口座別ではなく合計          |

会計取引から出す期末残高と、現金・預金の確認残高が一致しない場合に、差を預金等へ自動で押し込まない。未精算立替などの差異について[Q-06](../plans/accounting-export.md#未決事項)で計上範囲・基準を確認してから帳票へ反映する。

## 計算できる値と不足時の扱い

- 費目別合計と、次期繰越を含めた帳票の支出合計は計算できる。現金と預金の内訳は計算元がなければ取得・入力が必要。
- 残高未確認、対象期間との不一致、帳簿との未解消差異は出力前の修正事項として返す。
- 団体に顧問がいないと確認できた場合、顧問名がNULLでも欠損扱いにしない。
- 構造化データだけで自署・捺印済みという状態を生成しない。
