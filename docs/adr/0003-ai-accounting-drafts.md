# アップロードした書式の記入をAIに任せる

PoCでは、Solが大学別のセル対応表を渡さなくても基本ケースを編集できた。追加指示の比較では完了率が下がったため、現行指示を基に本体へ組み込む。

大学別Data Frameとセル配置を実装する方式に代え、DBからの取引取得、AIによる書式編集、成果物の取得を分ける。利用者が書式を渡すため、対応大学のカタログやExcel専用の生成経路を前提にしない。

今回の目的は、存在するデータで埋められる部分を埋めることである。追加の必須入力や独立した帳票検査は設けず、AIの説明とファイルを下書きとして返す。不足する事実は補わない。PoCの静的検査は実験の評価方法として残し、本体の生成条件には使わない。

[過去ファイルを恒久保存しない方針](0002-export-history-without-artifacts.md)は維持する。生成の待ち時間には提供元のバックグラウンド実行を使い、ファイルは受け取り期間中だけ保持する。実行記録と、削除を再試行するための情報をD1に置く。

以前の[3段階の設計](0001-separate-export-stages.md)は検討記録として残す。現在の仕様は[下書き生成の設計](../design/ai-accounting-drafts.md)で管理する。
