# 実行履歴を保存し、過去の出力ファイルは保存しない

エクスポートの実行者・条件・結果はDBへ保存し、詳細な処理ログを実行IDで関連付ける。利用要件に過去ファイルの再ダウンロードがないため、ファイルと入力Snapshot全体の恒久保存は行わない。

成果物を保存する方式なら同じファイルを返せるが、保管先・保持期間・アクセス・削除の運用が増える。初期はそれを持たず、再実行時は現在のDBから新しい実行として生成する。ハッシュを履歴へ持たせても、過去のファイルや入力の復元・完全再現は保証しない。

会計情報・年度プロフィール・領収書提出情報の保存は業務データの管理であり、この判断の対象外。エクスポート成功は大学への提出完了を意味しない。

状態・障害・記録項目の詳細は[実行処理](../design/export-execution.md)を参照する。
