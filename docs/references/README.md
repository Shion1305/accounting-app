## 原資料の扱い

| 原資料               | 今回の扱い       | 確認した理由                                                                                                     |
| -------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------- |
| 法政の記入済みブック | 同梱しない       | 実団体の記入済み取引と領収書画像があり、文書プロパティ・プリンタ情報にも個人・環境情報が残る                     |
| 学習院のブック       | 同梱を保留       | 個人を識別し得るプロパティに加え、`[Content_Types].xml`のローカルZIPヘッダ不正を確認。正常な空書式の再取得が必要 |
| 立命館のブック       | 同梱を保留       | 個人を識別し得るプロパティと、有効な機密分類ラベルがある。ラベルの意味・公開可否を確認せず除去して公開しない     |
| 早稲田の原本         | 原本は同梱しない | 作成者等の個人情報、内部保存先、共同編集・文書管理の識別子が残る。上記参照コピーのみ同梱                         |

原本は変更していない。`docs/.gitignore`で提供時の原資料の場所を除外し、確認済みの資料をこのディレクトリで管理する。機微情報を含む値・内部URL・識別子そのものは監査説明に転載しない。

## 早稲田参照コピーの変更範囲

- `docProps/core.xml`の作成者・最終更新者を除去。
- `docProps/custom.xml`と`customXml/`を除去。内部の文書管理情報や、不透明なDataMashup領域を含むため。
- `xl/workbook.xml`から、内部保存先だけを含むAlternateContentと共同編集のrevisionPtrを除去。
- 4つのプリンタ設定バイナリを除去。シートのpageSetupから、そのプリンタ設定へのリレーション属性だけを除去し、用紙・向き・倍率・余白等の設定は保持。
- 削除パーツを参照するリレーションとContent Typesを合わせて更新。

通常のブック再保存ではなく、必要なZIPパーツだけを変更した。セル値・数式・書式・共有文字列・入力規則・図形・コントロール・シート順・参照リストは編集していない。

## 確認結果と識別用ハッシュ

ZIPのCRC検査、全XMLの構文、残した内部リレーションの解決、元ファイルとの差分を確認した。シート1〜4はプリンタ設定への参照属性以外が元と一致し、シート5は完全一致。ほかの非対象10パーツもバイト単位で一致する。個人プロパティ・内部保存先・文書管理メタデータが残っていないことも確認した。

これは提供された版に対する内容・メタデータの確認であり、正式な提出先での受理や実際のExcel/PDF出力品質の検証を代替しない。

## 資料を更新する場合

1. 取得元・対象年度・版を記録し、本文・全シート・非表示領域・画像・コメント・埋込物・メタデータを確認する。
2. 機密分類が不明なものや公開可否を判断できない実データは、そのまま追加しない。個人情報だけでなく団体の会計内容も確認する。
3. 参照コピーを作る場合は元の内容・書式を維持し、除去内容・差分検証・元とコピーのハッシュを記録する。元資料を上書きしない。
4. 大学別の分析と入力契約、未決事項を同じPRで更新する。
