これらを、提供された版のフォーマットについて、大学別分析からセル・数式・説明をたどるための正本（source of truth）とする。Excelは原本から必要な情報を除去した**参照用の派生版**であり、未加工の公式配布物や、最新版の正式テンプレート、採用済みの製品生成用テンプレートではない。元の配置・項目名・説明が根拠であり、合成データの値や件数を大学の必須条件と解釈しない。

年度表記の不整合等は[早稲田の分析](../universities/waseda.md)、既存数式の問題は[法政の分析](../universities/hosei.md)に記録している。記入例をそのまま製品出力やテストの正解値へ流用せず、テスト用の会計入力は独立に作成する。横浜国立・明治の書式は未入手のため、推測したテンプレートを追加しない。

原本は変更していない。`docs/.gitignore`で提供時の原資料の場所を除外し、確認済みの資料をこのディレクトリで管理する。機微情報を含む値・内部URL・識別子そのものは監査説明に転載しない。

## 法政参照コピーの変更範囲

- `費目詳細!D1`の団体名と`入力例!E3`を「サンプル団体（架空）」に置換。
- `費目詳細`の4〜106行の明細入力欄（D〜K列、小計行・数式セルを除く）を消去し、4・7・13・46・104行に5件の合成例を設定。実取引の番号・金額・日付・内訳・用途・備考は引き継がない。
- `入力例`の6〜49行の明細入力欄（E〜L列、小計行・数式セルを除く）も消去し、元の記入済み16行に合成例を設定。説明上必要な「規模」「正課外」「実態」の番号表現は保持。
- 合成例の日付は2025年4月1日からの連番、金額・品名・用途は新規に設定。保存済みの数式計算値も合成例から更新し、元の会計合計を残さない。合成例の合計は`入力例!F50=13,600`、`費目詳細!E107=3,500`円。
- 未使用の共有文字列を除去し、参照番号を更新。見えるセルだけでなく、削除した団体名・取引文言が共有文字列に残らないことを確認。
- 領収書画像`xl/media/image1.png`と配置要素・参照を削除。機微情報のない波線画像と、番号・貼付方法等を示す説明図形は保持。
- 作成者・最終更新者、内部保存先、共同編集履歴、2つのプリンタ設定バイナリを除去。用紙・向き・余白など、プリンタ個体に依存しない印刷設定は保持。

数式本体・共有数式の定義、書式、行列サイズ、結合、非表示列、シート順、印刷範囲・タイトル、費目名は変更していない。元からある`入力例!J44:K44`・`J51:K51`、`費目詳細!I108:J108`の`#REF!`を含む式も保持する。これらの非表示列の式を、動作確認済みの製品計算ロジックとして使用しない。

## 学習院参照コピーの変更範囲

- `[Content_Types].xml`の圧縮ペイロードを復元し、中央ディレクトリに記録された圧縮長422 bytes・展開長1,840 bytes・CRC32 `bb181d1a`との一致を確認して正常なZIPへ格納。書式やContent Typesの内容を推測して作り直してはいない。
- 作成者・最終更新者、内部保存先、共同編集履歴、2つのプリンタ設定、文書サムネイルを除去し、関連するリレーション・Content Typesを更新。
- `書式`と`見本`の値・数式・書式・図形・説明文は保持。人物名が伏せられた既存の記入見本を、実取引のデータセットとは扱わない。

## 立命館参照コピーの変更範囲

- 作成者・最終更新者、内部保存先、共同編集履歴、プリンタ設定を除去。
- `docMetadata/LabelInfo.xml`と、それを参照するリレーション・Content Typesを除去。
- コメント6件の作成者を`Template`へ変更。日付書式・署名捺印に関する本文、セル位置、コメント図形は保持。
- 未記入の会計・人物欄、費目、現金／預金の繰越区分、集計式、書式・結合・署名欄は変更していない。

## 早稲田参照コピーの変更範囲

- `docProps/core.xml`の作成者・最終更新者を除去。
- `docProps/custom.xml`と`customXml/`を除去。内部の文書管理情報や、不透明なDataMashup領域を含むため。
- `xl/workbook.xml`から、内部保存先だけを含むAlternateContentと共同編集のrevisionPtrを除去。
- 4つのプリンタ設定バイナリを除去。シートのpageSetupから、そのプリンタ設定へのリレーション属性だけを除去し、用紙・向き・倍率・余白等の設定は保持。
- 削除パーツを参照するリレーションとContent Typesを合わせて更新。

通常のブック再保存ではなく、必要なZIPパーツだけを変更した。セル値・数式・書式・共有文字列・入力規則・図形・コントロール・シート順・参照リストは編集していない。

## 資料を更新する場合

1. 取得元・対象年度・版を記録し、本文・全シート・非表示領域・画像・コメント・埋込物・メタデータを確認する。
2. 個人情報だけでなく団体の実取引、領収書画像、未使用の共有文字列、数式キャッシュ、文書・分類メタデータも確認する。公開用コピーには実取引・個人情報を含めず、必要な記入例は架空と明示した合成データに置き換える。
3. 参照コピーではフォーマットの根拠となる項目・説明・書式・数式を維持し、除去・置換・修復内容と検証結果、元とコピーのハッシュを記録する。原本を上書きしない。既存の数式不備は別途記録し、匿名化に混ぜて修正しない。
4. 大学別の分析と入力契約、未決事項を同じPRで更新する。
