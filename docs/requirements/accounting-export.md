# 会計書類の下書き作成の要件

更新日: 2026-11-08

大学指定の書式と登録済みの会計データをAIに渡し、記入できる部分を埋めた下書きを取得する。PoCの結果を踏まえ、大学別のセル配置や分類コードを先に実装する方式から変更した。採用理由は[ADR](../adr/0003-ai-accounting-drafts.md)、実装の詳細は[下書き生成の設計](../design/ai-accounting-drafts.md)を参照する。

## 対象機能

- 認証済みのサークル管理者が、大学指定の書式をアップロードする。
- アップロードはPDF、Office文書、CSVとし、`.pdf`、`.xlsx`、`.doc`、`.docx`、`.pptx`、`.csv` を受け付ける。画像・アーカイブ・プログラムなどは対象外。
- 全期間または指定した期間の、サークルの登録済み収入・支出を使う。
- 必要なら年度、対象シート、希望形式などを依頼文で指定できる。
- 費目、用途、開始残高などがなくても、利用可能なデータだけで生成を進める。不足する事実は作らない。
- AIの説明と、生成した1件以上のファイルを取得できる。
- 処理中、途中終了、ファイルなし、通信失敗、期限切れを画面で区別する。
- 終了操作で一時ファイルを削除し、期限切れの記録も定期的に清掃する。

## 今回実装しないもの

大学別のマッピングや採点器、数式・表示・印刷の独立検査、正式提出の保証、自動提出、会話による再編集は含めない。特定の大学の正式テンプレートをアプリに登録する方式や、出力のために必須情報をDBへ追加する作業も行わない。

生成されたファイルは下書きとして返す。「生成完了」は品質検査への合格ではない。費目や記入位置の判断、ファイル編集はAIに任せる。

## 完了条件

- ダッシュボードから書式、期間、任意の依頼文を指定し、生成ファイルを取得できる。
- 不足項目を入力しなければ開始できない、という制約を設けない。
- 立替申請を反映済みの支出と重複計上せず、申請日を購入日として伝えない。
- 他サークルの取引、実行、生成ファイルにアクセスできない。
- APIキーを画面やモデルの実行環境に渡さない。
- 同じ開始リクエストの再送で、有料のモデル応答を重複して作らない。
- ファイルと入力全体を恒久保存せず、終了・期限切れで一時リソースを片付ける。
- 型チェック、lint、build、オフラインテストが通る。

従来の大学別Data Frame、Excel/PDFの品質要件、正式3大学対応の計画は、以前の方式の検討記録として関連設計に残す。現在の下書き作成機能の受入条件とは区別する。
